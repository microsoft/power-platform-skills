# Explainer video

[`site/explainer`](../../explainer/README.md) generates the captions in this folder.
Do not edit them by hand: change the script there and run its publish step.

The video and poster are served from this folder too, but they are not committed here.
The build copies them in from the `site-media` branch, pinned by `site/media.json`, so marketplace clones of `main` stay small.
See [Site media](../../README.md#site-media).

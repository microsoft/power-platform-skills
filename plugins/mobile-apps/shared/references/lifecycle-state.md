# Mobile App Lifecycle State

Generated mobile projects may be either mock-backed prototypes or real Dataverse-backed apps. Store the mode in:

```text
<project>/.code-apps-native/state.json
```

Schema:

```json
{
  "schemaVersion": 1,
  "dataMode": "prototype",
  "environment": null,
  "lastSyncedPlanHash": null,
  "lastDataverseManifestHash": null,
  "lastSyncAt": null
}
```

`dataMode` values:

| Value | Meaning |
|---|---|
| `prototype` | Screens use local mock services and seed JSON generated by `/create-mobile-prototype`. No real Power Platform environment is bound. |
| `dataverse` | `power.config.json`, `.datamodel-manifest.json`, generated services, connector schemas, and auth config are bound to a real environment. |

Rules:

- Do not set `dataverse` while `*.seed.json`, prototype mock-service markers, or connector throw-stubs remain under `src/generated/`.
- Do not store secrets, tokens, tenant user IDs, or connection IDs in this file.
- `environment` may contain non-secret environment URL/ID/tenant ID after conversion.
- `lastSyncedPlanHash` is the SHA-256 of `native-app-plan.md` after `/sync-from-plan` passes.
- `lastDataverseManifestHash` is the SHA-256 of `.datamodel-manifest.json` in Dataverse mode, otherwise `null`.

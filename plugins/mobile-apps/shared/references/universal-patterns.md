Compatibility index. Planners name only approved pattern keys in the screen
build pack. Builders read the one shard containing that key.

| Patterns | Shard |
|---|---|
| carousel, sparkline, shimmer, deep search, progress ring | [`universal-patterns/data-feedback.md`](universal-patterns/data-feedback.md) |
| biometrics, timeout, offline queue, alert banner, voice input | [`universal-patterns/trust-input.md`](universal-patterns/trust-input.md) |

## Selection rule

Industry is vocabulary/context only; it never selects visual composition.
Choose a pattern because the approved Product Experience and Workflow Journey
need that interaction. Record the exact pattern name and shard in the build
pack or per-screen spec. A builder reads no shard when the pack names no
universal pattern.

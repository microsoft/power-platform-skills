# Design System

Route to exactly one design workflow. Do not preload both instruction files.
Read [`reference-ownership.json`](./reference-ownership.json) once and load only
the references owned by the selected mode. This developer-authored manifest is
never generated by a planner and never becomes a project contract.

## Automatic native mode

Use [`automatic-native.md`](./automatic-native.md) only when all are true:

- `CODE_APPS_NATIVE_ORCHESTRATING=1`;
- `.tmp/experience-contract.json`, `.tmp/experience-foundation-contract.json`,
  and `.tmp/experience-screen-contract.json` exist;
- no explicit brand, logo, URL, design document, Figma, screenshot,
  design-intake, gallery, comparison, style, refresh, reskin, theme, history,
  sibling-app, Canvas app, or Power Pages option was requested.

This is the normal `/create-mobile-prototype` path. It asks no brand, cost,
style, HTML, or screenshot question and makes no nested design-model call.

## Optional mode

For every explicit visual input or standalone/refresh/reskin/theme/history
request, read [`optional-modes.md`](./optional-modes.md) only. That file owns
mode-specific reference loading and security. Do not read
`automatic-native.md` unless the optional workflow explicitly returns to the
automatic baseline after the maker cancels its override.

## Required outputs

Both paths write and validate:

- `brand/design-system.md`;
- `brand/tokens.ts`;
- 2-5 Product Experience Primitives;
- complete semantic color, typography, spacing, shape, state, motion, media,
  and accessibility decisions;
- provenance distinguishing supplied, explicit, inferred, and absent brand
  evidence.

Automatic mode also writes `.tmp/design-context-evidence.json` with exact
files/bytes read and `designModelCalls: 1`. Optional paths record their selected
mode and inputs in design provenance/history.

Run the mobile changed-file validator for every file written. Return `DONE`,
`DONE_WITH_CONCERNS:`, `NEEDS_CONTEXT:`, or `BLOCKED:` as the literal first
line. A static gallery is optional review material and never native evidence.

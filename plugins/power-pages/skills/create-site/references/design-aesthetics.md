# SPA design adapter

Read and apply [shared site design quality](../../../references/site-design-quality.md) first, then the [SPA design adapter](../../../references/design-aesthetics.md). The implementation guidance now lives at that shared plugin path; do not maintain a second copy here.

SPA sites use their entry HTML (`index.html` or the framework equivalent), theme, and `browser_snapshot`/screenshot workflow as the SPA adapter and `create-site` prescribe. Non-SPA sites use [their own adapter](../../edit-site/references/styling/design-quality.md), not SPA font loading, theme replacement, or a dev server.

# Code-site design adapter

Read and apply [shared site design quality](../../../references/site-design-quality.md) first, then the [code-site design adapter](../../../references/design-aesthetics.md). The implementation guidance now lives at that shared plugin path; do not maintain a second copy here.

Code sites use their entry HTML (`index.html` or the framework equivalent), theme, and `browser_snapshot`/screenshot workflow as the code-site adapter and `create-site` prescribe. Classic sites use [their own adapter](../../style-site/references/design-quality.md), not SPA font loading, theme replacement, or a dev server.
